## About me

I'm a Computer Science student who builds complete, working applications, from the interface to the
backend and the data. My main interests are **AI-powered and full-stack web applications**, followed
by **web security** and **blockchain**.

- Building document-grounded AI assistants with retrieval-augmented generation (RAG)
- Designing security tools that explain *why* something is risky, not just *that* it is
- Applying zero-knowledge proofs to real privacy problems
- **Open to full-time roles and internships** in AI, full-stack development and security
